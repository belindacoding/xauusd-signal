# XAUUSD Daily Signal

每个交易日 22:17 UTC（纽约收盘后）自动计算 XAUUSD 信号：

- **通知**：每天一个新 Issue，标题即信号（`XAUUSD 信号 2026-07-10: LONG/FLAT`），并指派给仓库所有者触发邮件通知
- **历史**：`signals/` 目录按日归档全部输出，用于日后对账
- 策略：Grind Momentum（主）+ GC-Composite v1（参考）+ Shadow Short（纸面追踪）
- 研究依据：本地项目 `XAUUSD_Strategy_Research/RESEARCH_AGENDA.md`

手动触发：Actions → XAUUSD Daily Signal → Run workflow
